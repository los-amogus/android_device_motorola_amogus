## Device Tree

Unified LineageOS 24 device configuration (`lineage_amogus`) for Motorola **SM6125 (`trinket`)** devices.

### Supported Devices

| Device | Codename |
| --- | :---: |
| Moto G8 / Moto G Fast (2020) | `rav` |
| Moto G Power (2020) | `sofia` |
| Moto G Stylus / Moto G Pro (2020) | `sofiap` |
| Moto G8 Power (2020) | `sofiar` |
